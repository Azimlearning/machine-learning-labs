## 2. Product Principles

1. **Reproducible from a clean clone.** `requirements.txt` plus the dataset list must be enough to re-run every notebook.
2. **Evidence over claims.** `results/labNN/` is generated by notebooks, never hand-edited.
3. **Honest evaluation.** Leakage rules from lab notes Ch. 3.7 are binding.
4. **Understand, then submit.** Tests follow the labs, so code must be explainable.
5. **Docs stay current.** Changelog every session; STATUS never rounds up.

---

## 3. Architecture

A flat course workspace, no application. Docs and agent config at the repo root, lab material in `ML LAB/`.

### 3.1 Components

| Area | Path | Purpose |
|---|---|---|
| Docs | `refdocs/` | PRD, STATUS, plans, execution, changelog, guides |
| Agent config | `CLAUDE.md`, `.claude/` | Rules, subagents, commands |
| Lab workspace | `ML LAB/` | Datasets, notebooks, models, results, requirements |
| Slides | `ML LECTURE/` | Lecture PDFs (local only) |

### 3.2 Data & state

Eleven public Kaggle datasets downloaded manually into `ML LAB/all_datasets/` (list in `all_datasets/README.md`). Models serialise with joblib into `models/`; evidence lands in `results/labNN/`. No database.
